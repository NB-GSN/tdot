# Tag der offenen Tür – Informatik am GSN

Präsentation „Informatik am GSN“ für den Tag der offenen Tür.

- Am Handy: normale Scrollseite zum Nachlesen
- Am Beamer: Button „Präsentation starten“ (Vollbild, Folien wechseln automatisch alle 12 Sekunden; Pfeiltasten, P = Pause, Esc = Ende)
- Direkt im Präsentationsmodus öffnen: Adresse mit `#praesentation` am Ende
